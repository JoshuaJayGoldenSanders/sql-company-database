# SQL Company Database Project

This project demonstrates SQL database fundamentals.

Concepts practiced:
- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- CONSTRAINTS
- ALTER TABLE
- INSERT statements
- SELECT queries

Tables:

Departments:
- DepartmentID (Primary Key)
- DepartmentName

Employees:
- EmployeeID (Primary Key)
- Name (NOT NULL)
- DepartmentID (Foreign Key)
- Salary (NOT NULL)
- Age

This project is part of my journey transitioning into software development focusing on SQL and backend fundamentals.
